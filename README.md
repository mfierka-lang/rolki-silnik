# Silnik montażu rolek

Program w Go, który lokalnie montuje krótkie pionowe filmy: rozpoznaje mowę, wycina pauzy, dodaje napisy i składa rolkę.
To repozytorium służy do budowy i testów na macOS w GitHub Actions.

Fonty w `silnik/szablon/fonty` i `silnik/interfejs/zasoby` (Bricolage Grotesque, Figtree, Instrument Serif) są na licencji
SIL Open Font License 1.1. Wykrywanie twarzy: pigo (MIT). Pozostały kod: wszelkie prawa zastrzeżone.
